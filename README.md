# InteractVid_Ai-Powerd-Interactive-Video-Learning-Platform
🎥 InteractVid – AI Powered Interactive Video Learning Platform

InteractVid is an AI-powered interactive learning platform that transforms passive video learning into an active and engaging experience. The system uses AI chatbots, automatic question generation, voice interaction, and progress tracking to improve student understanding and knowledge retention during video-based learning.

🚀 Features

- 🎥 Interactive Video Player
- 🤖 AI Chatbot for Doubt Clarification
- ⏸ Auto Pause During Video Playback
- ❓ AI-Generated Questions
- 📝 AI Notes & Summary Generator
- 🎤 Voice-Based Interaction Support
- 📊 Learning Progress Tracking
- 🔐 Personalized Learning Experience

🛠 Tech Stack

Frontend

- HTML
- CSS
- JavaScript

Backend

- Node.js

Database

- MongoDB

AI Integration

- Gemini API / OpenAI API

⚙️ Algorithms Used

- Natural Language Processing (NLP)
- Question Generation Algorithm
- Event-Based Trigger Algorithm

- Improve student engagement
- Provide instant doubt clarification
- Enhance understanding and knowledge retention
- Create a smart AI-based learning environment
